# 🏆 Olimpíadas de Programação PUC Minas — 2026/2

Repositório dedicado às minhas soluções para os desafios das Olimpíadas de Programação da **PUC Minas**, referentes ao semestre **2026/2**.

O objetivo é praticar lógica de programação, desenvolver o raciocínio algorítmico e aprimorar minhas habilidades em resolução de problemas utilizando C#.

## 🛠️ Tecnologias

- **Linguagem:** C#
- **Plataforma de desafios:** [Beecrowd](https://judge.beecrowd.com/)
- **Ambiente de desenvolvimento:** Visual Studio Code e .NET

## 📂 Organização do repositório

Os desafios são organizados individualmente, com cada problema contendo seu próprio projeto C#.

```text
Olimpiadas-Programacao-PUC-2026-2/
├── README.md
├── Desafio01/
│   ├── Desafio01.csproj
│   └── Program.cs
├── Desafio02/
│   ├── Desafio02.csproj
│   └── Program.cs
└── ...
```

Cada pasta contém a implementação de um desafio, facilitando a execução, a manutenção e a evolução das soluções.

## ▶️ Como executar

É necessário ter o [.NET SDK](https://dotnet.microsoft.com/download) instalado.

1. Clone o repositório:

   ```bash
   git clone https://github.com/1PedroCoelho/Olimpiadas-Programacao-PUC-2026-2.git
   ```

2. Acesse a pasta do desafio desejado:

   ```bash
   cd Olimpiadas-Programacao-PUC-2026-2/Desafio01
   ```

3. Execute o programa:

   ```bash
   dotnet run
   ```

> **Observação:** os nomes das pastas e o endereço do repositório devem corresponder aos utilizados no GitHub.
